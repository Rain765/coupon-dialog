ZamCash Reward Motion — 一圈最终版（2026-10-15）

最终确认：卡片绕竖直中轴（Y 轴）翻转 1 圈，累计 360°；18 个爆散粒子（14 金星 + 4 微光），保留拖尾。文案更新为召回还款抵扣券；金额、截止时间和资格由业务数据驱动，配色和原始素材不变。

交付入口
- handoff/README.md：文件与使用说明。
- handoff/FRONTEND-INTEGRATION.md：时间线、缓动、接入与低性能降级方式。
- python3 handoff/package.py：生成 output/zamcash-reward-final.zip，并校验文件、哈希和运行资源预算。
- ZIP 内 demo/ 是完整可运行实现，docs/ 是前端说明；references/ 的原始 README 只供历史追溯。

最终参数
- 大星星：0–640 ms。
- 18 粒子：400–480 ms 错峰开始，最迟 1728 ms 消失。
- 卡片翻转：600–1800 ms，rotateY(-360deg) → rotateY(0deg)。中间关键帧 45.067141% 为 -120deg。
- 第一段 cubic-bezier(.336590,.296449,.603158,.690273)；第二段 cubic-bezier(.230493,.438551,.530806,1)。保留原有节奏和柔和停稳，仅将角度缩至一圈。
- 卡片放大：600–2000 ms，scale(.08) → scale(1)，cubic-bezier(.35,0,.5,1)。
- 按钮：1450–2200 ms 渐显，动画结束后解锁；不能改成固定 setTimeout 解锁。
- 就绪装饰仅播放 2 次，正常播放最迟 8600 ms 全部停止。

体积
HTML/SVG gzip level 6 + PNG/WebP 原始字节：约 76.9 KB，精确体积与剩余预算见交付包 asset-manifest.json。
不含 HTTP 头、交付文档和 ZIP 容器开销。线上需为 HTML/SVG 开启 gzip；Python 预览服务不自动压缩。

降级
- 低性能开关、系统 prefers-reduced-motion：素材准备/超时判断后直接静态卡片，按钮可用。
- 主图等待超过 1200 ms：内联 SVG 兜底；后来加载成功只换图，不重播。
- 图片失败：保持 SVG 兜底；当前实例没有自动失败重试复位。
- 页面隐藏：暂停 CSS 时间线，恢复可见后继续。
- 未内置自动低端机检测；接入方依据宿主策略选择静态分支。

验证
- 最终版每 5 ms 采样旋转矩阵并展开角度，累计 360°；粒子数量 18；旋转时长 1200 ms。
- 正常申请入口、低性能模式与系统减少动态模式通过，逐帧预览完成。
- 先前版本已检查重播、窄屏、暂停、素材失败/延迟和离线；本次保留一圈参数，更新召回文案、动态数据与接入说明。
- 开场 star-v2.webp、原始 README.txt、asset-prompts.txt 不变；reward-v2.webp 按要求更新为红色飘带版本。目标市场低端手机真机尚未验证。

业务接入
- 6 个自然日内申请，还款时抵扣；不是 6 天内还款。
- RewardCoupon.show 接收 id、amount、eligible、status、expiresAt、serverNow；生产初始化必须禁用默认模拟券。
- 只有 eligible=true、status=available 且未过期时展示；按钮通过 onApply 交给宿主申请流程。
- 过期隐藏、重复点击保护、组件 destroy、申请失败事件与更新竞争处理详见接入说明。

2026-10-16 移动端线条修复
- WebKit 手机模拟复现旧虚线缺失，两个 SVG 请求均为 200；该环境旧外框可见，未完全复现反馈中的外框消失。
- 券外框改为原轮廓内联 SVG + 1px 非缩放描边；虚线改为原生 CSS border-left，消除外部 SVG 背景和旋转细线依赖。原始素材文件不修改。
- WebKit 对照确认：原虚线 SVG height=0.5 时 naturalHeight=0 且 decode 报 EncodingError；仅将 height 改为 1 即可解码并绘制。最终采用原生 CSS 虚线避免该问题。
- Chromium 与 WebKit 各通过 32 项浏览器断言；新外框与虚线已截图检查，低端真机仍待验收。
