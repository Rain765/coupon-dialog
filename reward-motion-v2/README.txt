Reward Motion V2 — 轻量奖励动效

使用：解压整个文件夹后打开 index.html。保持两个 WebP 文件与 HTML 位于同一文件夹。无外部字体、CDN 或 JS 依赖。

交付文件：
index.html — 可交互演示和完整源码
star-v2.webp — 开场独立星星（360 x 360）
reward-v2.webp — 星星、金币、丝带装饰（480 x 320）
asset-prompts.txt — 内置 image_gen 生成方式与完整提示词

体积（十进制 KB，不含 HTTP 头和说明文件）：
HTML 源码：22,735 字节
HTML gzip：7,721 字节
两张 WebP：49,878 字节
启用 HTML gzip 后总量：57,599 字节
未压缩页面与图片总量：72,613 字节
本机 Python 预览服务未启用 gzip；线上需由服务器/CDN 开启。

动画：星星先入场，随后过渡到装饰与卡片；主体 2.2 秒。装饰浮动与闪光仅播放有限次数。低性能模式与系统减少动态效果设置均直接呈现最终卡片。页面进入后台暂停动画。
素材超过 1.2 秒未加载完时先展示矢量兜底卡片，素材加载完成后显示高清装饰。素材加载失败时保留可用卡片。金额和业务文字仍由代码控制。

验证：Chrome 中检查了出场与最终状态、金额切换、领取反馈、低性能模式、窄屏宽度和图片加载失败兜底。尚未在目标市场低端手机真机验证，也未接入实际奖励服务。USD、示例账户与领取状态均为演示。

接入：使用 .scene、.veil 相关结构和样式；脚本 play() 控制演示。接入真实产品时替换演示金额、币种、文案与领取处理。颜色为本演示用途，未修改任何 Figma 颜色定义或组件库。
